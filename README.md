# portfolio-demo

Сайт-портфоліо UI-дизайнера. Next.js (App Router) + TypeScript + Tailwind CSS v4.

- План сайту: [docs/site-plan.md](docs/site-plan.md)
- Наступний крок: дизайн-токени та компоненти, потім перший екран.

## Запуск

```bash
npm install
npm run dev
```

Відкрити http://localhost:3000
